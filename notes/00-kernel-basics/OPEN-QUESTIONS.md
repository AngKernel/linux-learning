# 后续实验选项

当前资料生成不依赖用户决定，八篇均已交付。以下是进入运行验证时需要固定的实验条件，不影响本次合并。

1. **v6.18 VM 与接口**：使用环境任务最终提供的 VM 和真实接口名替换示例 eth0；硬件 RSS/IRQ 验证需要多队列设备，不能用 loopback 代替。
2. **工具版本**：工具篇 bpftrace 示例采用 0.24 语法；若环境任务安装其他版本，后续验证应按该版本核对字段语法并记录实际版本。
3. **比较版本**：DPDK 官方概念页访问时显示 26.07.0，VPP 页面为 25.10；若后续要与用户现有项目逐字段比较，应先固定项目实际版本，不能把本文概念映射当作 ABI 对照。
4. **RT 扩展范围**：当前按非 PREEMPT_RT 解释主规则；若后续学习目标含实时内核，另补 RT 的软中断、锁与分配行为，不把当前表格直接外推。
