## 几个跨篇概念

| 容易混淆的说法 | 本批笔记使用的准确含义 |
|---|---|
| socket “预分配内存” | 必须分清记账额度与实际分配的物理存储，见 A2 |
| “包被 clone” | 可能复制描述符而共享载荷；描述符引用与数据引用不同，见 A1 |
| “零拷贝完成” | 指定接口规定的缓冲区生命期事件，不自动等于对端应用读完，见 A3 |
| “backlog” | B1 是 per-socket 待处理 skb；B3 的 RPS backlog 是 per-CPU 输入队列；listener 的半连接/accept 队列另有职责 |
| “RCU 安全” | 还要看保护的是 slab 页还是对象、是否持引用、是否复查身份，见 B2 |
| “无锁 listener” | 收包绕过 listener 的 socket 大锁；accept queue、ehash 写端和引用/计数仍有同步，见 B3 |
