# 待环境确定的事项

资料写作无阻塞问题；下列事项只影响后续实验复现，不需要现在暂停并等待确认。

| 事项 | 建议默认做法 | 需要补充的信息 |
|---|---|---|
| QEMU 网络对端与地址 | 使用 guest 外的 host/另一 guest 作为 TCP 对端，从控制台执行 trace；示例中的 192.0.2.0/24 是待替换地址。 | P3 最终网络拓扑、guest/peer IP、virtio 接口名；必须确保流量经过 virtio，不能走 loopback。 |
| 可追踪内核与运行模式 | 第一次用普通非 RT 内核、默认 NAPI，不额外启用 XDP/AF_XDP/RPS/threaded NAPI。 | 实际 kernel config、ftrace 可见符号、virtio 模块参数及协商的 offload/RSS 能力。 |
| 实测产物保存位置 | 按全仓库约定，由环境/实验负责人将正式 trace 放到 `traces/`；本任务仅在本目录记录命令与示意。 | 实验实跑会话由哪个任务负责、记录的内核构建标识与配置。 |

本任务不改动全局环境、不安装或更换驱动、不编写用户态 TCP 协议栈。以上选择可以在后续实验会话确定；两个章节的源码核查与提交已独立完成。
