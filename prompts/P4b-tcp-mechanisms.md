章节安排：
第 3 章 TCP 连接生命周期
  listen/accept 与半连接、全连接队列；三次握手在源码中的完整路径；request_sock 与 syncookies；TCP 状态机的处理函数；四次挥手与 TIME_WAIT

第 4 章 TCP 可靠性与性能机制
  ACK 处理；乱序队列；重传与各类定时器；SACK/RACK；拥塞控制框架（插拔式 ops 接口）以 CUBIC 为例；接收窗口与缓冲区自动调优；Nagle、delayed ACK、TSO/GSO 与 TCP 的关系

每章统一格式：
1. 一张总览图（Mermaid 时序图或流程图）

4. "为什么这样设计"：至少 3 条，结合性能、并发、可扩展性
5. 验证实验：在 QEMU 虚拟机里可以运行的 bpftrace、ftrace function_graph 或 perf 命令，用来亲眼看到这条路径，并附上预期输出的样子

7. 对用户态协议栈的启示（2–3 条）
